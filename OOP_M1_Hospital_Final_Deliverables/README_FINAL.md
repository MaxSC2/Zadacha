# Финальный пакет — ООП Модуль 1 «Больница»

Главные файлы:

- `ООП_Модуль_1_Отчет_Больница_ИСУ-24-1_финал.docx` — редактируемый отчёт.
- `ООП_Модуль_1_Отчет_Больница_ИСУ-24-1_финал.pdf` — готовая PDF-версия.
- `UML_Hospital.png` — диаграмма для вставки/просмотра.
- `UML_Hospital.svg` — векторная версия диаграммы.
- `UML_Hospital.dot` — редактируемый Graphviz-исходник.
- `hospital_project_final.zip` — архив финальной Python-реализации.
- `REQUIREMENTS_TRACEABILITY.csv` — матрица требований и проверки.
- `FINAL_AUDIT.md` — итоговый аудит.
- `CHANGE_LOG.md` — перечень изменений и причин.

Исходный код запускается командой `python main.py` из распакованного архива проекта.
